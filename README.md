## 🚀 Despliegue en GitHub Pages

### Paso 1: Crear Repositorio
1. Crear nuevo repositorio en GitHub
2. Nombrar: `forestalypaisajismoyd.github.io` (recomendado)
3. Configurar como público

### Paso 2: Subir Archivos
```bash
git init
git add .
git commit -m "Initial commit - ForestalyPaisajismoYD landing page"
git branch -M main
git remote add origin https://github.com/[usuario]/forestalypaisajismoyd.github.io.git
git push -u origin main
```

### Paso 3: Activar GitHub Pages
1. Ir a **Settings** del repositorio
2. Scroll hasta **Pages**
3. En **Source**, seleccionar **Deploy from a branch**
4. Seleccionar **main** branch y **/ (root)**
5. Hacer click en **Save**

### Paso 4: Acceder al Sitio
- URL: `https://[usuario].github.io/forestalypaisajismoyd`
- O si usó el nombre recomendado: `https://forestalypaisajismoyd.github.io`

## 🔧 Personalización

### Cambiar Colores
Modificar las variables CSS en `:root`:
```css
:root {
    --verde-principal: #2e7d32;
    --verde-claro: #81c784;
    --cafe-madera: #795548;
    --blanco: #ffffff;
}
```

### Actualizar Información de Contacto
Buscar y reemplazar los números de WhatsApp y email en:
- Enlaces de botones
- Sección de contacto
- Footer
- Meta tags

### Modificar Servicios
Editar la sección `.servicios-grid` para:
- Cambiar íconos (Font Awesome)
- Actualizar títulos y descripciones
- Agregar/quitar servicios
